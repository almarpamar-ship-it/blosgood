
<section class="info-section" id="acerca">
  <h2>Acerca de TaskBol</h2>
  <p>
    TaskBol es un proyecto en desarrollo que busca reunir
    oportunidades de tareas y recompensas en una página
    adaptada a dispositivos móviles.
  </p>
  <p>
    Actualmente, las tareas y los puntos mostrados son
    demostrativos. No ofrecemos pagos reales todavía.
  </p>
</section>

<section class="info-section" id="condiciones">
  <h2>Condiciones de uso</h2>
  <p>
    Utiliza el sitio de manera responsable. Las funciones
    de recompensas reales estarán disponibles únicamente
    cuando se hayan implementado y verificado.
  </p>
  <p>
    No pagues ninguna tarifa para desbloquear recompensas.
  </p>
</section>

<section class="info-section" id="privacidad">
  <h2>Política de privacidad</h2>
  <p>
    Esta versión de TaskBol es una demostración y no
    dispone de un sistema de cuentas ni de pagos reales.
    No introduzcas contraseñas, datos bancarios ni
    documentos personales.
  </p>
  <p>
    Antes de integrar publicidad, analítica o cuentas,
    publicaremos una política que explique qué datos
    se recopilan, para qué se utilizan y cómo se protegen.
  </p>
</section>
